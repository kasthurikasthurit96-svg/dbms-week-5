
# Week 5 – Payment Transaction Management System

## Project Overview
This project focuses on managing customer payment transactions in an e-commerce database using MySQL. It records payment details, tracks transaction status, and generates payment-related business reports.

## Objectives
- Create a Payment table.
- Establish a relationship between Orders and Payment.
- Store different payment methods.
- Manage successful, failed, and pending transactions.
- Analyze payment methods used by customers.
- Calculate total revenue and average transaction amount.
- Generate customer payment history.

## Database
Database Name: ecommerceD__B

## Payment Table Attributes
- Payment_ID
- Order_ID
- Payment_Date
- Payment_Mode
- Payment_Status
- Transaction_Amount

## Constraints Used
- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- NOT NULL
- CHECK

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT
- UPDATE
- WHERE
- GROUP BY
- ORDER BY
- COUNT()
- SUM()
- AVG()
- INNER JOIN

## Payment Methods
- UPI
- Credit Card
- Debit Card
- Net Banking
- Cash on Delivery

## Reports Generated
1. Successful payment report.
2. Failed transaction report.
3. Pending payment report.
4. Payment mode analysis.
5. Revenue analysis.
6. Customer payment history.

## Tools Used
- MySQL
- MySQL Workbench

## Conclusion
This project demonstrates how SQL can be used to manage payment transactions, track payment statuses, and generate useful revenue reports in an e-commerce database.
